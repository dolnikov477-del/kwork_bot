# Kwork Bot

Бот, который следит за новыми заказами на Kwork, присылает уведомление
в Telegram с кнопками «Перейти к заказу» и «Сгенерировать отклик» (через
бесплатный ИИ Groq).

## Что нужно получить перед запуском

1. **Telegram Bot Token**
   Напиши в Telegram боту `@BotFather` → `/newbot` → следуй инструкциям →
   скопируй токен вида `123456:AAAбукв-и-цифр`.

2. **Твой chat_id**
   Напиши боту `@userinfobot` — он пришлёт твой ID (число).

3. **Groq API key (бесплатно)**
    Зайди на https://console.groq.com → зарегистрируйся → в разделе API Keys
    создай новый ключ.

4. **ID категории Kwork**
   Зайди на https://kwork.ru/projects, слева выбери нужную категорию
   (например «Разработка и IT» → «Скрипты и боты»), посмотри на адрес
   страницы — там будет `?fc=ЧИСЛО`. Это число и есть ID категории.
   Можно указать несколько через запятую.

## Настройка

Скопируй `.env.example` в `.env` и заполни:

```
TELEGRAM_BOT_TOKEN=токен_от_botfather
TELEGRAM_CHAT_ID=твой_id
GROQ_API_KEY=твой_ключ_groq
KWORK_CATEGORY_IDS=39,41
KEYWORDS=сайт,бот,парсинг,лендинг
```

## Локальный запуск (для проверки)

```bash
python -m venv venv
source venv/bin/activate      # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Деплой на Railway

1. Залей эту папку как репозиторий на GitHub
2. На railway.app → New Project → Deploy from GitHub repo
3. Railway сам увидит `Dockerfile` и соберёт образ (Chromium уже внутри)
4. В настройках проекта (Variables) добавь все переменные из `.env`
5. Готово — сервис работает в фоне 24/7 и присылает заказы в Telegram

## Если парсер перестал находить заказы

Kwork может немного менять вёрстку сайта. В этом случае нужно поправить
селекторы в файле `kwork_parser.py` (там сверху есть подробная инструкция,
как их найти через "Просмотреть код" в браузере за 2 минуты) — просто
пришли мне новые классы, и я поправлю код.

## Важно понимать

- Это парсинг публичной страницы, официального API у Kwork нет — сайт
  теоретически может измениться или временно заблокировать частые запросы.
  Если это случится, поможет увеличение `POLL_INTERVAL` или прокси.
- База данных (`seen_orders.db`) хранится на диске сервиса. Если Railway
  пересоздаст контейнер с нуля, история "виденных" заказов обнулится —
  это не страшно, просто разок придут уже виденные заказы повторно.
